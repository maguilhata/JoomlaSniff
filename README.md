Uma ferramenta automatizada de segurança desenvolvida para identificar vulnerabilidades, mapear superfícies de ataque e auditar aplicações baseadas no CMS **Joomla**. 

O objetivo principal desta ferramenta é auxiliar profissionais de segurança (Pentesters) e administradores de sistemas a encontrar falhas antes que sejam exploradas por agentes maliciosos.

---

## 🚀 Funcionalidades

A ferramenta executa três funções principais de forma integrada:

* **Scanner de Portas Abertas:** Mapeia portas e serviços ativos no servidor para identificar possíveis vetores de entrada ou serviços desnecessários expostos.
* **Interceptador de Requisições:** Analisa o tráfego HTTP/HTTPS direcionado ao Joomla para verificar cabeçalhos de segurança ausentes, falhas de autenticação e parâmetros vulneráveis.
* **Fuzzer de Diretórios Ocultos:** Executa força bruta (brute-force) estruturada para localizar arquivos de configuração expostos, painéis administrativos e diretórios ocultos específicos do ecossistema Joomla.
