# JoomlaSniff 🕵️‍♂️

Ferramenta de reconhecimento e análise de segurança para sites que utilizam **Joomla CMS**.

![Python](https://img.shields.io/badge/Python-3.8%2B-blue)
![License](https://img.shields.io/badge/License-MIT-green)

## 📌 Sobre

O **JoomlaSniff** foi desenvolvido para auxiliar em testes de segurança autorizados, identificando possíveis vulnerabilidades em instalações Joomla. A ferramenta realiza:

- **Scan de portas abertas** (21, 22, 80, 443, 3306, 8080, entre outras)
- **Análise de headers HTTP** (CORS, CSP, X-Frame-Options, HSTS, etc.)
- **Teste de SQL Injection** com payloads conhecidos de componentes Joomla
- **Descoberta de diretórios e arquivos expostos** (admin, backups, configurações sensíveis)
